# MovieHub - TMDB Movie Panel

React + Vite movie application using the TMDB API.

## Features
- Popular Movies
- Top Rated Movies
- Upcoming Movies
- Global movie search
- Movie detail page
- Cast section
- Pagination
- Responsive design
- Reusable React components

## Setup
1. Run `npm install`
2. Open `src/api.js`
3. Replace `YOUR_TMDB_API_KEY` with your TMDB API key.
4. Run `npm run dev`
